O problema do delay()

Iniciantes frequentemente usam a função delay(). O problema é que essa função pausa completamente o processador (busy-wait). Para projetos reais, utilizamos a função millis(), que retorna o número de milissegundos desde que a placa foi ligada, permitindo multitarefa cooperativa.

blink_without_delay.ino 
// Prática recomendada: Evitar delay()
const int ledPin = 13; 
unsigned long previousMillis = 0; 
const long interval = 1000; // 1 segundo

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  unsigned long currentMillis = millis();

  // Verifica se o tempo decorrido atingiu o intervalo
  if (currentMillis - previousMillis >= interval) {
    previousMillis = currentMillis; 
    
    // Inverte o estado do pino
    digitalWrite(ledPin, !digitalRead(ledPin));
  }
}

Protocolo I2C

Comunicação síncrona de 2 fios (SDA + SCL).

  • Endereçamento de 7 ou 10 bits.
  • Velocidade padrão: 100kHz / Rápido: 400kHz.
  • Requer resistores de pull-up nas linhas.

Pinos PWM

Pulse Width Modulation (Modulação por Largura de Pulso).

  • Simula saídas analógicas variando o duty cycle.
  • Frequência base no Uno: ~490 Hz.
  • Uso: analogWrite(pin, 0-255)
